[Unsigned DSL](https://dropexitjoin.github.io/unsigned-dsl/) is a browser-based tool for representing block-based Minecraft codelines as plain text instead of in-game building. Includes universal **AI prompt** for working with this coding language.

Its a single self-contained HTML page with a simple editor: text representation on the left textbox, resulting item command on the right. It can convert in both directions. Includes error-handling and syntax highlighting.

Main use cases:
- Use the included AI prompt to have any AI model write, edit and review your code
- Save code as text files (practically infinite backup storage)
- Take a look at your code as text. Its easier to navigate, search and replace than in-game

Runs entirely in the browser, no install or setup needed.
